# План тестирования block_0x06 (POI spatial index)

## Текущее состояние

В `test_block_0x06.py` реализован **один тест**: `test_init_block` — проверка инициализации блока (dbrev, segsize).
Класс `POI_ITEM` и метод `get_all_items` не покрыты тестами.

## Что нужно протестировать

### 1. POI_ITEM — парсинг и структура

| № | Тест | Что проверяет |
|---|------|---------------|
| 1.1 | `test_poi_item_unpack` | Корректность распаковки struct `POI_ITEM_struct` (>LHHHHHHLLL, 28 байт) |
| 1.2 | `test_poi_item_cat_enum` | Корректное преобразование en_cat → `en_POI_CAT` |
| 1.3 | `test_poi_item_repr` | Строковое представление `__repr__` |
| 1.4 | `test_poi_item_is_custom` | Флаг `is_custom` для портов/аэропортов (1) и обычных POI (0) |
| 1.5 | `test_poi_item_zero_flags` | `NotImplementedError` при non-zero zero1/zero2 |

### 2. POI_ITEM — координаты и бренд

| № | Тест | Что проверяет |
|---|------|---------------|
| 2.1 | `test_poi_item_coord_calculation` | LOCAL_X/Y → абсолютные координаты: `base + (local << 8)` |
| 2.2 | `test_poi_item_brand_parsing` | Извлечение бренда из name blob по BRAND offset |
| 2.3 | `test_poi_item_no_brand` | BRAND == 0 → `item.brand == ''` |
| 2.4 | `test_poi_item_coord_step_64` | Верность шага 64: `max(LOCAL_X) == (X_max - X_min)/64 - 1` |

### 3. block_0x06 — инициализация и структура

| № | Тест | Что проверяет |
|---|------|---------------|
| 3.1 | `test_block_06_area` | `MAP_AREA` корректно загружен (left_bottom, right_top) |
| 3.2 | `test_block_06_s0_list` | `s0_li_items` имеет верные ptr/cnt |
| 3.3 | `test_block_06_s1_zero` | `NotImplementedError` при non-zero S1 |
| 3.4 | `test_block_06_item_count_matches` | `s0_li_items.cnt == len(list(get_all_items()))` |

### 4. get_all_items — полный перебор

| № | Тест | Что проверяет |
|---|------|---------------|
| 4.1 | `test_get_all_items_basic` | Базовый перебор без `is_load_extended` |
| 4.2 | `test_get_all_items_sorted` | Items отсортированы по `LOCAL_X` (ascending) |
| 4.3 | `test_get_all_items_all_have_coord` | У каждого item есть `item.coord` (не None) |
| 4.4 | `test_get_all_items_brand_coverage` | Проверка брендов: branded POI → brand loaded, others → '' |

### 5. get_all_items — extended mode

| № | Тест | Что проверяет |
|---|------|---------------|
| 5.1 | `test_extended_loads_bladdr` | `is_load_extended=True` → `item.bladdr` не None |
| 5.2 | `test_extended_loads_poi` | `is_load_extended=True` → `item.poi` не None |
| 5.3 | `test_extended_bladdr_valid` | `item.bladdr` → валидный блок 0x10 |
| 5.4 | `test_extended_poi_ptr_match` | `item.poi` соответствует смещению `item._ptr10` |

### 6. Валидация координат

| № | Тест | Что проверяет |
|---|------|---------------|
| 6.1 | `test_coord_within_map_area` | Все координаты POI внутри `block.area` |
| 6.2 | `test_coord_exact_match_with_0x10` | Координата из 0x06 == координате в 0x10 detail (для нескольких записей) |

### 7. Edge cases

| № | Тест | Что проверяет |
|---|------|---------------|
| 7.1 | `test_empty_block` | Блок с cnt=0 → пустой итератор |
| 7.2 | `test_single_item_block` | Блок с 1 item |
| 7.3 | `test_large_block` | Блок с большим количеством items (1000+) |
| 7.4 | `test_all_poi_categories` | Все категории `en_POI_CAT` представлены |

### 8. Производительность

| № | Тест | Что проверяет |
|---|------|---------------|
| 8.1 | `test_iteration_performance` | Время итерации по большому блоку < X ms |

## Зависимости

- Требуется доступ к fixture файлам `bnl_0x8f4a06.bin` и `ru30_06_0x9e8601.bin`
- Для extended-тестов нужен доступ к блокам 0x10 (POI details)
- Для теста 6.2 нужен парсер блока 0x10 (`block_0x10.get_poi`)
