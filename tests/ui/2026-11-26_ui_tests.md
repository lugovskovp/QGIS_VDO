# Тестирование Qt-части плагинов QGIS

## Структура проекта QGIS_VDO

```
QGIS_VDO/
├── vdo/                    # логика парсинга (покрыта тестами)
├── ui_files/               # Qt-классы
│   ├── ConfigurationDialog.py   # QDialog настроек
│   ├── QgisVdoDockwidget.py     # Основной dock-виджет
│   └── drawing.py               # Рисование на карте
└── tests/
    └── vdo/                    # pytest-тесты
```

## Подходы к тестированию

### 1. Тестирование создания виджетов (без QGIS)

Самый простой и быстрый способ. Создаём `QApplication` вручную.

```python
import sys
import pytest
from PyQt5.QtWidgets import QApplication

@pytest.fixture(scope="module")
def qapp():
    """Единственный QApplication на модуль."""
    app = QApplication.instance()
    if app is None:
        app = QApplication(sys.argv)
    yield app

def test_dialog_creation(qapp):
    """Диалог настроек создаётся без ошибок."""
    from ui_files.ConfigurationDialog import ConfigurationDialog
    dialog = ConfigurationDialog(parent=None)
    assert dialog is not None
    dialog.close()
```

### 2. Тестирование через `qgis.utils` (с QGIS)

```python
def test_plugin_can_be_loaded():
    """Плагин загружается без ошибок."""
    from qgis.utils import plugins
    plugin = plugins['QGIS_VDO']
    assert plugin is not None
```

### 3. Тестирование с mock-iface

```python
from unittest.mock import MagicMock

def test_initGui_creates_menu():
    from QGIS_VDO import QGIS_VDO
    plugin = QGIS_VDO()
    mock_iface = MagicMock()
    plugin.iface = mock_iface
    plugin.initGui()  # не должно бросить
```

### 4. pytest-qt (продвинутый)

def test_dialog_with_qtbot(qtbot):
    from ui_files.ConfigurationDialog import ConfigurationDialog
    dialog = ConfigurationDialog(parent=None)
    qtbot.addWidget(dialog)
    dialog.show()

## Сводная таблица

| Подход | Нужен QGIS | Скорость | Что покрывает |
|---|---|---|---|
| Создание виджетов | Нет | ⚡ | Инициализация, виджеты |
| Через `qgis.utils` | Да | 🐢 | Запуск плагина |
| С mock-iface | Нет | ⚡ | initGui/unload |
| pytest-qt | Нет | ⚡ | Сигналы, клики, ввод |
| Integration | Да | 🐢 | Полный цикл |
